# Provenance

helpdrift was written independently, from scratch, starting from a public,
generic problem description: documentation that silently goes stale when code
changes. That problem is widely discussed and is not owned by anyone.

- No proprietary source code, documentation, marketing copy, prompts, UI, or
  designs from any existing product were used, consulted while writing, or
  copied.
- No code was copied from other open-source projects in this space. Where
  similar tools exist, they were known only at the level of "this category of
  tool exists".
- Dependencies: the Go standard library only.
- The code, tests, fixtures, prompts, and documentation were written with AI
  assistance and reviewed by the author, Victor Motricala.
